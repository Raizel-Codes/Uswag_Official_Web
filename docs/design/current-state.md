### Tokens and fonts
- `styles/tokens.css`: `--color-deep/primary/sage/mist`, the semantic status colors, and `--font-display` (Lora), `--font-heading` (Poppins), `--font-body` (Inter).
- `tailwind.config.js`: `forest`, `primary` (+`light #3D7455`), `sage`, `mist`, status colors, font families `display/heading/body`, and a `pulse-ring` keyframe.
- `index.html` loads Inter 400–700, Lora 400–700 with italics, and Poppins 500–800 from Google Fonts.
- `styles/index.css`: `body` = mist/forest/Inter, and **all `h1–h6` = `font-display` globally** (this affects the portals too; see conflicts). There is a global reduced-motion override that forces `[data-reveal]` and `.draw-path` to their final state.

### Motion infrastructure (already installed, so no new dependencies are needed)
- **`gsap` ^3.15 + `@gsap/react`** are already in `package.json`.
- `lib/motion.ts`: one-time ScrollTrigger registration, refresh on `load` and `fonts.ready`, `prefersReducedMotion()`, and the `EASE` and `DURATION` constants.
- `hooks/useScrollReveal.ts`: animates each `[data-reveal]` (y 28→0, 0.9s `power3.out`) and toggles `.is-visible` for Tailwind `group-[.is-visible]` companions.
- `components/common/CountUp.tsx`: a scroll-triggered number tween that respects reduced motion.
- **A history note inside `HomePage.tsx:78-86`:** a therecord-style pinned hero was already tried and **removed**, because GSAP `pin` fought the `position: fixed` Header and caused a visible jump. The new plan must not pin anything under that header.

### Decorative components
- `CornerFrame.tsx`: L-bracket corners (sage or primary, **hex hardcoded**).
- `OrnamentalDivider.tsx`: diamond, leaf and dot flourish (**hex hardcoded**).

## 4. Conflicts and issues

### Plan-level conflicts (these need a decision)
1. **Organization name.** Your brief says "**Unified Student** Working for Advocacy and Growth". The Constitution (`docs/01 …pdf`, line 2), `CLAUDE.md`, `index.html`, the Footer and `plan_extracted.txt` all say "**United Students** Working for Advocacy and Growth". Only the unused gold SVG says "Unified Student". CLAUDE.md treats the Constitution as the source of truth, so I will use **United Students** unless you tell me the name was changed by amendment.
2. **Founding history is not in the repo.** The Constitution's ratification line is blank ("Ratified this ____ day of ________"). There is no founding year, no founder names and no milestones anywhere in `docs/`. A "years in between" timeline needs **real facts from you**. I will not invent history for a real organization.
3. **The approved prototype.** CLAUDE.md names `prototype/landingDesktop.html` as the **approved** visual reference for the public site. The time-travel redesign departs from it in section order, the archival palette layer and the hero concept. Per CLAUDE.md I have to ask: **does this brief supersede `landingDesktop.html` for `/`?**
4. **Shared Header, Footer and MobileStickyBar.** An archival-to-modern hero wants a header that sits on parchment at the top of the page. The Header is shared with 11 other public pages. Options are in the architecture doc.
5. **Typefaces.** CLAUDE.md fixes the public site at Lora + Inter and says not to change the pairing silently. A classical feel can be done in Lora alone (italics, tracked caps, old-style figures). If you want a third "engraved" or "typewriter" display face, that is a deliberate pairing change and needs your approval.

### Existing defects on `/`, which the rebuild would fix
- **Placeholder numbers shipped in production:** "486 Active Members", "3", "12 Events / Month" (`HomePage.tsx:197-202`, comment: "placeholder figures"). CLAUDE.md forbids placeholder content in production paths.
- **The hero image alt text is wrong** (see §2).
- **Hardcoded hex** `bg-[#142718]` at line 220, `#1877F2` for Facebook blue, and hex inside `CornerFrame` and `OrnamentalDivider`. CLAUDE.md says to never hardcode hex.
- **`bg-white` sections and cards** fall outside the four-token palette.
- **Tailwind `text-gray-400`** for empty states (2.54:1 on white, fails AA).
- **Invalid Tailwind classes** that do nothing: `stroke-dasharray-[300]` and `stroke-dashoffset-[300]` (not core utilities), and `duration-250`, `duration-600`, `duration-400` (not in the default scale). The icon draw-on effect probably never runs.
- **`MobileStickyBar`** sets `paddingBottom` and then `padding` in the same style object, so the safe-area inset is overwritten.
- The `index.html` viewport has **`maximum-scale=1.0`**, which blocks pinch-zoom (WCAG 1.4.4). The file is shared, so this is flagged here and not in scope.

## 5. Portal isolation check
Portals share `tokens.css`, `tailwind.config.js`, `index.css` (the global `h1–h6 { font-display }` rule) and `index.html`. If new landing tokens live in a separate `landing.css` that is **imported only by the landing page chunk** and scoped under a `.lp` root class, the portals cannot be affected. The shared `Logo`, `CornerFrame` and `OrnamentalDivider` components must only gain optional props, and their current defaults must stay the same.
