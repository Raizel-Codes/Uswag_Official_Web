# PWA Icons

Place the following here before building for production (referenced in `vite.config.ts`):

- `icon-192x192.png`
- `icon-512x512.png`
- `apple-touch-icon.png`

Generate from a single square source logo in the design palette (`#142718` / `#2E5B41` on transparent or `#E7EFE4` background). Maskable icon needs safe-zone padding — see https://maskable.app to preview.
